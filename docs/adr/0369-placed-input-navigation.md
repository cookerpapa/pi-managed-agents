# ADR-0369. Navigate adopted input history and preserve unread Agent mail at Stop

Accepted for the isolated #52 composition. Session input admission, Pi placement and receipt confirmation retain the ordering in ADR-0366. The canonical user Entry carries its verified sender class. It also retains any original presentation that differs from Pi's model input, including attachment references. Input navigation and transcript jumps read these Entries within the same frozen Flow bounds. Their visibility, lifetime and collection follow the existing history rules. Sealed answer IDs remain available to transcript Fork and prune actions. Queue editing and withdrawal remain Session-scoped.

Stopping a Turn pauses inter-agent delivery for that Session. Pending and reserved Agent messages whose placement was absent at the ordered cutoff are held in the Session mailbox, as are subsequent arrivals during this pause. A held Agent message has no Turn assignment. A newly admitted human Turn releases the pause and binds these messages to itself, preserving their identity, order and delivery mode. Its opening user input comes first. When a successor was admitted during cancellation, finalization sends the predecessor's remaining Agent messages there. Existing user draft returns and independent child leases retain their semantics. Ordinary completion continues to roll pending mail forward. Writer replacement resumes the existing Turn and reconciles reservations at the old writer's ordered seal.

The Codex CLI multi-agent v2 [Stop test](https://github.com/openai/codex/blob/rust-v0.167.1/codex-rs/core/src/session/turn_input_tests.rs#L857-L900) verifies that ordinary child mail can remain unread without waking an interrupted root. Pi Managed Agents uses its existing PG queue and native placement receipt to retain mail across the reservation-to-publication boundary.
