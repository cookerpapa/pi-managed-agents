# ADR-0371. Retain settled history on Worker-local SSD

Accepted for the isolated #52 composition. A Worker owns an optional private local directory, a 20 GiB disk cache and 24-hour retention. Memory keeps ADR-0370's 256 MiB and five-minute defaults. Reads use the PG-confirmed tenant, Session, Flow and terminal version, validate native coverage, and fall through memory, SSD and the existing PG cold path. Active handoff keeps its sealed recovery path.

Use SQLite through the repository runtime's built-in Node binding on a dedicated I/O thread. The development acceptance used Node 24.12.0 and its bundled SQLite 3.50.4. SQLite's public-domain distribution supplies the local transaction manager and crash recovery that a raw append-file implementation would otherwise need to coordinate with a separate index. [Upstream licensing](https://www.sqlite.org/copyright.html). Transactions replace the version index, prune obsolete Entries and append new immutable Entries atomically. An exact cached parent allows delta writes. Bootstrap or replacement writes the selected prefix once. The original native order, inherited/local distinction, byte weights and payload checksums are retained. SQLite's rollback journal handles interruption within the local transaction; deleting the private cache is a complete rollback. [Atomic commit](https://sqlite.org/atomiccommit.html) · [SQLite space and durability settings](https://sqlite.org/pragma.html) · [Node SQLite binding](https://nodejs.org/docs/latest-v24.x/api/sqlite.html).

The Worker advertises committed disk versions with tier, size class and expiry over its existing management connection, including after a restart with the same directory. Eviction of one tier publishes the remaining tier. The scheduler prefers an available memory holder, then an available SSD holder, and applies the existing bounded grace to large histories. Neither cache admission nor cache I/O grants execution authority. SQLite failure degrades to the remaining tiers. All data stays outside Guest access. Production cutover remains gated under #48.
